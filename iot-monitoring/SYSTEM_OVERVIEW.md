# 🏠 Smart Home IoT 모니터링 시스템 - 전체 구성도

## 📋 시스템 개요

라즈베리파이 기반의 완전 자동화된 스마트 홈 IoT 모니터링 시스템으로, 실시간 센서 데이터 수집부터 웹 대시보드, 완벽한 유지보수 시스템까지 포함한 엔터프라이즈급 솔루션입니다.

## 🎯 핵심 구성 요소

### 1. 📱 프론트엔드 시스템
- **기술 스택**: React 18, Tailwind CSS, Recharts, Lucide React
- **주요 기능**:
  - 실시간 센서 데이터 시각화
  - 24시간 히스토리 차트
  - PDLC 조명 원격 제어
  - 반응형 모바일 지원
  - WebSocket 실시간 업데이트

### 2. 🚀 백엔드 API 시스템
- **기술 스택**: Node.js, Express.js, PostgreSQL, WebSocket
- **주요 기능**:
  - RESTful API 제공
  - 실시간 WebSocket 통신
  - 센서 데이터 저장 및 조회
  - 알림 시스템
  - CORS 및 보안 설정

### 3. 🍓 라즈베리파이 센서 시스템
- **기술 스택**: Python 3, GPIO 라이브러리, Adafruit 센서
- **센서 구성**:
  - **DHT22**: 온도/습도 측정
  - **PM2.5**: 미세먼지 농도
  - **소음 센서**: 환경 소음 + ANC 효과
  - **PDLC 필름**: 스마트 조명 제어
- **제어 기능**:
  - 실시간 데이터 수집
  - API 서버 전송
  - 제스처 기반 제어
  - 자동 오류 복구

### 4. 💾 데이터베이스 시스템
- **기술**: PostgreSQL 14+
- **구조**:
  - 디바이스 관리 테이블
  - 센서 데이터 테이블 (파티셔닝)
  - 알림 이벤트 테이블
  - 제어 로그 테이블
- **최적화**:
  - 인덱스 최적화
  - 자동 데이터 정리
  - 백업 및 복구

## 📊 시스템 메트릭 및 모니터링

### 실시간 모니터링 지표
```yaml
시스템 리소스:
  - CPU 사용률: < 80% (경고), < 90% (위험)
  - 메모리 사용률: < 85% (경고), < 95% (위험)
  - 디스크 사용률: < 90% (경고), < 95% (위험)

애플리케이션 성능:
  - API 응답 시간: < 2초 (정상), < 5초 (경고)
  - 에러율: < 1% (정상), < 5% (경고)
  - WebSocket 연결: 실시간 모니터링

센서 데이터:
  - 온도: 15-30°C (정상 범위)
  - 습도: 30-70% (정상 범위)
  - PM2.5: < 35㎍/㎥ (좋음), < 75㎍/㎥ (보통)
  - 소음: < 60dB (조용), < 80dB (보통)
```

## 📅 자동화 스케줄

### Cron 작업
```bash
# 매일 새벽 2시 - 데이터베이스 백업
0 2 * * * node backup-system.js database

# 매일 새벽 3시 - 로그 로테이션
0 3 * * * node log-manager.js rotate

# 매주 일요일 새벽 4시 - 파일 백업
0 4 * * 0 node backup-system.js files

# 매일 새벽 5시 - 오래된 백업 정리
0 5 * * * node backup-system.js cleanup

# 매시간 - 성능 메트릭 수집
0 * * * * node performance-monitor.js
```

### Systemd 서비스
```bash
# 자동 시작 서비스
- iot-watchdog.service: 시스템 워치독
- iot-maintenance-dashboard.service: 유지보수 대시보드
- postgresql.service: 데이터베이스
```

## 🛠️ 설치 및 실행

### 빠른 시작
```bash
# 1. 전체 시스템 설치
cd smart-home-iot/iot-monitoring
./start.sh install

# 2. 유지보수 시스템 설치

./install.sh --with-systemd

# 3. 전체 시스템 시작
./start.sh all

# 4. 유지보수 시스템 시작
```
