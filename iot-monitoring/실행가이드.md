# 🏠 Smart Home IoT 모니터링 시스템 - 실행 가이드

## 📋 빠른 시작

### 1️⃣ 통합 실행 스크립트 사용 (권장)

```bash
# 프로젝트 디렉토리로 이동
cd /home/user/smart-home-iot/iot-monitoring

# 실행 권한 부여 (최초 1회)
chmod +x start.sh

# 전체 시스템 실행 (백엔드 + 프론트엔드)
./start.sh

# 또는 모든 서비스 실행 (백엔드 + 프론트엔드 + ANC)
./start.sh --all

# 백엔드만 실행
./start.sh --backend

# 프론트엔드만 실행
./start.sh --frontend

# ANC 시스템만 실행
./start.sh --anc
```

### 2️⃣ 개별 서비스 실행

#### 백엔드 서버 실행
```bash
cd /home/user/smart-home-iot/iot-monitoring/backend
npm install  # 최초 1회만
node server.js
# 또는
npm start
```

#### 프론트엔드 대시보드 실행
```bash
cd /home/user/smart-home-iot/iot-monitoring/frontend/iot-dashboard
npm install  # 최초 1회만
npm start
```

#### ANC 시스템 실행
```bash
cd /home/user/smart-home-iot/iot-monitoring/anc_system
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python anc_elite.py 200
```

## 🔧 주요 코드 파일

### 백엔드 (Backend)

**`backend/server.js`** - Express API 서버
- RESTful API 엔드포인트
- WebSocket 서버
- PostgreSQL 데이터베이스 연결
- 센서 데이터 수집 및 저장
- 공기질 API 연동

주요 기능:
- `GET /api/health` - 헬스 체크
- `GET /api/sensor/current` - 현재 센서 데이터
- `GET /api/sensor/temperature-humidity` - 온습도 데이터
- `POST /api/sensor/temperature-humidity` - 센서 데이터 수신
- `GET /api/noise` - 소음 데이터
- `GET /api/air-quality` - 공기질 데이터
- `GET /api/pldc/status` - PDLC 조명 상태
- `POST /api/pldc/toggle` - PDLC 조명 제어

### 프론트엔드 (Frontend)

**`frontend/iot-dashboard/src/App.js`** - React 메인 컴포넌트
- 실시간 대시보드 UI
- 센서 데이터 시각화 (Recharts)
- WebSocket 실시간 업데이트
- 반응형 디자인 (Tailwind CSS)

주요 페이지:
- 홈 대시보드: 전체 센서 데이터 요약
- 온습도 상세: 온도/습도 차트 및 통계
- 소음 분석: 노이즈 캔슬링 효과 시각화
- 공기질 모니터링: PM2.5, PM10 데이터

### ANC 시스템

**`anc_system/anc_elite.py`** - 노이즈 캔슬링 시스템
- 실시간 소음 분석
- 적응형 노이즈 캔슬링 알고리즘
- API 서버로 데이터 전송

### 라즈베리파이 센서

**`raspberry-pi/dht_to_db.py`** - 온습도 센서 스크립트
- DHT22 센서 데이터 수집
- API 서버로 전송

**`raspberry-pi/pdlc_sync.py`** - PDLC 조명 제어
- GPIO를 통한 PDLC 필름 제어
- 제스처 인식 연동

## 🗄️ 데이터베이스 설정

### PostgreSQL 설치 및 설정

```bash
# PostgreSQL 설치 (Ubuntu/Debian)
sudo apt-get update
sudo apt-get install postgresql postgresql-contrib

# PostgreSQL 시작
sudo service postgresql start

# 데이터베이스 생성
sudo -u postgres psql
CREATE DATABASE iot_monitoring;
CREATE USER iot_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE iot_monitoring TO iot_user;
\q
```

### 환경 변수 설정

**`backend/.env`** 파일 생성:
```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=iot_monitoring
DB_USER=iot_user
DB_PASSWORD=your_password
PORT=3001
```

## 🔍 문제 해결

### 포트 충돌
```bash
# 포트 3000 사용 중인 프로세스 확인
lsof -ti:3000

# 프로세스 종료
lsof -ti:3000 | xargs kill -9

# 포트 3001 사용 중인 프로세스 확인
lsof -ti:3001 | xargs kill -9
```

### 데이터베이스 연결 오류
- PostgreSQL이 실행 중인지 확인: `sudo service postgresql status`
- `.env` 파일의 데이터베이스 정보 확인
- 데이터베이스가 생성되었는지 확인

### 프론트엔드 빌드 오류
```bash
# node_modules 삭제 후 재설치
rm -rf node_modules package-lock.json
npm install
```
