# 🏠 Smart Home IoT 시스템 - 전체 하드웨어 구성도

## 📋 시스템 개요

라즈베리파이 5와 Pico를 활용한 스마트 홈 IoT 모니터링 및 ANC(능동 소음 제거) 통합 시스템입니다.

## 🔌 하드웨어 구성 상세

### A. 🍓 라즈베리파이 5 + 센서 + 릴레이

```
┌──────────────────────────────────────────────────────────────────────┐
│                        🍓 Raspberry Pi 5                             │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   ┌──────────────────┐          ┌──────────────────┐                │
│   │  🌡️ DHT11 센서   │          │  ⚡ 릴레이 모듈    │                │
│   │   (온도/습도)     │          │   (PDLC 제어)     │                │
│   └────────┬─────────┘          └────────┬─────────┘                │
│            │                              │                          │
│   ┌────────┴──────────────────────────────┴─────────┐               │
│   │              GPIO 핀 연결                         │               │
│   ├───────────────────────────────────────────────────┤               │
│   │                                                   │               │
│   │   DHT11 센서:                                     │               │
│   │   • VCC  ──────► 3.3V (Pin 1)                    │               │
│   │   • GND  ──────► GND  (Pin 6)                    │               │
│   │   • DATA ──────► GPIO4 (Pin 7)                   │               │
│   │                                                   │               │
│   │   릴레이 모듈:                                    │               │
│   │   • VCC  ──────► 5V   (Pin 2)                    │               │
│   │   • GND  ──────► GND  (Pin 14)                   │               │
│   │   • IN   ──────► GPIO17 (Pin 11)                 │               │
│   │                                                   │               │
│   │   릴레이 출력:                                    │               │
│   │   • COM/NO ────► PDLC 필름 AC 전원               │               │
│   │                                                   │               │
│   └───────────────────────────────────────────────────┘               │
│                                                                      │
│   📡 네트워크: Wi-Fi                                                 │
│   🔗 통신: HTTP POST → Backend API (localhost:3001)                 │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

#### GPIO 핀 맵핑 테이블

| 장치 | 핀 | GPIO | 설명 |
|------|-----|------|------|
| DHT11 VCC | Pin 1 | 3.3V | 센서 전원 |
| DHT11 GND | Pin 6 | GND | 접지 |
| DHT11 DATA | Pin 7 | GPIO4 | 온습도 데이터 |
| 릴레이 VCC | Pin 2 | 5V | 릴레이 전원 |
| 릴레이 GND | Pin 14 | GND | 접지 |
| 릴레이 IN | Pin 11 | GPIO17 | 제어 신호 |

#### MEMS 마이크 연결 상세

| 마이크 | 역할 | ADC 핀 | 저항 |
|--------|------|--------|------|
| 마이크 1 | 주 경로 (원본 소음) | GP26 (ADC0) | 1kΩ 직렬 |
| 마이크 2 | 보조 경로 (레퍼런스) | GP27 (ADC1) | 1kΩ 직렬 |

## 📊 통신 프로토콜 요약

| 경로 | 프로토콜 | 데이터 형식 |
|------|----------|-------------|
| Pico → 노트북 | USB Serial | ADC 값 (16bit) |
| 노트북 → Backend | HTTP POST | JSON |
| RPi5 → Backend | HTTP POST | JSON |
| Backend → Frontend | WebSocket | JSON |
| Backend ↔ PostgreSQL | TCP/IP | SQL |
| 노트북 → TPA3116 | 3.5mm Audio | Analog |

## 🎛️ 소프트웨어 구성

### Raspberry Pi 5
```python
# dht_to_db.py
- DHT11 센서 읽기 (Adafruit_DHT)
- HTTP POST → Backend API
- 1분마다 데이터 전송
```

### Raspberry Pi Pico
```python
# main.py (Thonny로 업로드)
- ADC0 (GP26): 주 마이크 샘플링
- ADC1 (GP27): 보조 마이크 샘플링
- USB Serial → 노트북 전송
```

### 노트북 (ANC 처리)
```python
# anc_elite.py
- USB Serial 수신 (Pico 데이터)
- LMS 알고리즘 → 역위상 파형 생성
- sounddevice → 3.5mm 오디오 출력
- HTTP POST → Backend (ANC 상태)
```

## 🚀 실행 순서

```bash
# 1. PostgreSQL 시작
sudo service postgresql start

# 2. Backend 시작
cd backend && node server.js

# 3. Frontend 시작
cd frontend/iot-dashboard && npm start

# 4. Raspberry Pi 5에서 센서 스크립트 실행
python3 dht_to_db.py

# 5. Pico에 main.py 업로드 (Thonny 사용)

# 6. ANC 시스템 시작
cd anc_system
source venv/bin/activate
python anc_elite.py 200
```
