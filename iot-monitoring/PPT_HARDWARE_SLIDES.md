## 슬라이드: 하드웨어 구성 A - 라즈베리파이 5

### 🍓 Raspberry Pi 5 + 센서 + 릴레이

| 장치 | GPIO 핀 | 기능 |
|------|---------|------|
| **DHT11 센서** | GPIO4 | 온도/습도 측정 |
| **릴레이 모듈** | GPIO17 | PDLC 필름 ON/OFF |

```
         3.3V ──► DHT11 VCC
          GND ──► DHT11 GND
        GPIO4 ──► DHT11 DATA
        
           5V ──► 릴레이 VCC
          GND ──► 릴레이 GND
       GPIO17 ──► 릴레이 IN
                      ↓
                 PDLC 전원 제어
```

## 슬라이드: 하드웨어 구성 B - Pico + MEMS 마이크

### 🔧 Raspberry Pi Pico + 듀얼 마이크

| 마이크 | ADC 핀 | 역할 |
|--------|--------|------|
| **MEMS 1** | GP26 (ADC0) | 주 경로 (원본 소음) |
| **MEMS 2** | GP27 (ADC1) | 보조 경로 (레퍼런스) |

```
  MEMS 마이크 ──[1kΩ]──► Pico ADC
                 ↑
     신호 안정화 + 과전류 방지
     
  Pico ──USB──► 노트북
```

📝 **Thonny**로 main.py 업로드

## 슬라이드: 하드웨어 구성 C - ANC 출력 회로

### 🎧 ANC 음향 출력 시스템

```
노트북      →     TPA3116 앰프     →     Dayton 진동자
  │                   │                      │
3.5mm 오디오      12~24V DC              소음 상쇄
```

| 장치 | 연결 | 역할 |
|------|------|------|
| **노트북** | 3.5mm Jack | ANC 신호 출력 |
| **TPA3116** | 12~24V DC | 신호 증폭 |
| **Dayton 진동자** | 앰프 출력 | 역위상 진동 발생 |

## 슬라이드: GPIO 핀 맵핑 요약

### Raspberry Pi 5
| 핀 | GPIO | 장치 | 기능 |
|-----|------|------|------|
| Pin 1 | 3.3V | DHT11 | 전원 |
| Pin 7 | GPIO4 | DHT11 | 데이터 |
| Pin 2 | 5V | 릴레이 | 전원 |
| Pin 11 | GPIO17 | 릴레이 | 제어 |

### Raspberry Pi Pico
| 핀 | 기능 | 장치 |
|-----|------|------|
| GP26 | ADC0 | MEMS 마이크 1 (주 경로) |
| GP27 | ADC1 | MEMS 마이크 2 (보조 경로) |
| 3.3V | 전원 | 마이크 VCC |
| GND | 접지 | 마이크 GND |

## 슬라이드: 실행 순서

```bash
# 1. PostgreSQL 시작
sudo service postgresql start

# 2. Backend 시작 (포트 3001)
cd backend && node server.js

# 3. Frontend 시작 (포트 3000)
cd frontend/iot-dashboard && npm start

# 4. RPi5 센서 스크립트
python3 dht_to_db.py

# 5. Pico main.py 업로드 (Thonny)

# 6. ANC 시스템 시작
python anc_elite.py 200
```
